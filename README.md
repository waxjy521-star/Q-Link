# Q-Link

Q-Link 是一个 Qt × QQ 融合风格的网页即时通讯平台开发起点。当前版本提供可运行的账号系统、好友申请、私聊、群聊、在线状态和个人资料。

## 环境要求

- Node.js 20 或更新版本
- npm
- 建议使用电脑完成首次安装和启动；启动后可通过同一局域网或部署域名在手机浏览器访问

## 本地启动

1. 解压项目并进入 `Q-Link` 文件夹。
2. 复制 `.env.example` 并命名为 `.env`。
3. 在 `.env` 中设置 `JWT_SECRET`，建议使用足够长的随机字符串。
4. 安装依赖：

   ```bash
   npm install
   ```

5. 启动：

   ```bash
   npm start
   ```

6. 浏览器打开 `http://localhost:3000`。

首次注册两个账号后，可以互相搜索账号并发送好友申请。对方接受后即可私聊。群聊创建后，当前版本还没有邀请成员的界面，后续版本会补上成员邀请、群管理和群公告。

## 当前功能

- 注册、登录、密码哈希存储、JWT 登录状态
- 个人昵称、简介和头像地址
- 用户搜索、好友申请、接受和删除好友 API
- 好友私聊、群聊消息
- Socket.IO 实时消息和在线状态
- 深色 / 浅色主题
- 响应式布局，适配窄屏手机

## 重要说明

这是 Q-Link 的第一阶段开发版，不是已经完成安全审计的商业级通讯产品。

- 当前使用 SQLite，适合本地开发和单机部署；多实例部署需要迁移到 PostgreSQL 等共享数据库。
- 当前没有端到端加密。不要发送密码、证件信息、住址等敏感内容。
- 当前没有图片/文件上传、语音/视频通话、消息撤回、消息搜索、群成员邀请和推送通知。
- 头像字段暂时保存图片 URL。生产环境应增加安全的文件存储和 URL 校验。
- 正式公开部署前应增加限流、邮箱/手机验证、密码重置、审计日志、备份、HTTPS、内容安全策略和更严格的 CORS 配置。
- `JWT_SECRET` 必须保密，不能提交到 GitHub。
